# Phases 2 à 6 — Projets & Récents, Rapide, Projet, PWA, Electron : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Livrer le reste de la spec en une passe (demande de l'utilisateur : « tout d'un coup ») : plusieurs projets avec Récents et exports conservés, mode Rapide, mode Projet (+ PDF), PWA installable avec mise à jour proposée, app Electron Mac/Windows publiée sur GitHub Releases.

**Architecture:** Bibliothèque de projets dans IndexedDB (index + un enregistrement par projet, images partagées, exports par projet) derrière `src/library/`. Rapide et Projet rendent leurs vignettes avec le moteur 3D existant via le bac à sable `inSandbox` (`src/variants/render.ts`), le `Viewport` étant monté hors écran sur ces écrans. PWA via `vite-plugin-pwa` (mode prompt). Electron dans `desktop/` charge le même `dist` par un protocole `app://` fixe ; `electron-updater` + bannière commune.

**Tech Stack:** existant + `vite-plugin-pwa`, `pdfjs-dist`, `electron`, `electron-builder`, `electron-updater`.

**Spec:** `docs/superpowers/specs/2026-10-12-ui-redesign-design.md` (§ 4, 5, 6, 10, 12, 13, 14).

## Global Constraints

- Aucune fonctionnalité existante perdue ; les autosauvegardes et `.json` existants s'ouvrent (migration automatique de la clé `project` vers la bibliothèque).
- Exports conservés : 10 derniers par projet, plafond global 500 Mo, les plus anciens supprimés en premier, jamais de projet supprimé automatiquement ; `navigator.storage.persist()` demandé.
- Détection du support : règles exactes de la spec § 5 (r = largeur/hauteur) ; « à confirmer » si r est à moins de 5 % d'une frontière.
- PDF : `pdfjs-dist` chargé à la demande, page rendue à 200 dpi plafonnée à 4096 px.
- PWA : mode `prompt`, ne recharge jamais sans accord ; désactivée dans Electron.
- Electron : origine fixe `app://mockuplab`, build web avec `BASE_PATH=/` ; mise à jour : Windows installe en un clic, macOS non signé propose et ouvre la page de release.
- Aucun `git push` ni tag sans accord ; commits sans `Co-Authored-By`.
- Tous les textes via l'i18n FR/EN ; pas de tirets cadratins dans les nouveaux textes.

## Review Focus

1. **Migration** : un utilisateur qui avait un projet autosauvé (ancienne clé `project`) le retrouve dans Récents et à la réouverture, avec ses images — tâche 1.
2. **Images partagées** : supprimer un projet ne doit pas effacer une image encore utilisée par un autre — tâche 1.
3. **Rapide sans image** : la galerie montre un exemple et « Télécharger » fonctionne ; changer d'écran pendant le rendu ne casse ni le projet ni la file — tâche 4.
4. **Projet avec images de supports mélangés** : chaque image va sur un appareil compatible, le héro contient au plus 5 supports, le ZIP contient héro + 1 par image (+ planche) — tâche 6.
5. **Mise à jour** : la bannière n'apparaît que lorsqu'une nouvelle version existe, et « Plus tard » la ferme sans recharger — tâches 8 et 9.
