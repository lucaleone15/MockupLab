# Retours 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cleaner Studio (no Ambiance, Devices page with a catalogue window, colour-first Décor, sorted Brand), one Export window for image and video, a "Voir sur…" network-interface preview instead of the carousel, named projects whose exports can be found and resumed, and a blue product-style home page.

**Architecture:** React + zustand UI changes on the existing rail pages (`src/studio`, `src/app/panels`), the export sheet (`src/shell/ExportSheet.tsx`) absorbing `src/animation/VideoSection.tsx`, a new `src/social/` module (preview overlay + 2D painter for export), export history extended with project snapshots in `src/library/exports.ts`, and a rewritten `src/home/Home.tsx`.

**Tech Stack:** Vite, React 19, TypeScript, Tailwind 4, R3F/three, zustand + zundo, idb-keyval, Playwright check scripts (dev server on :5173).

**Spec:** `docs/superpowers/specs/2026-10-20-retours-2-design.md`

## Global Constraints

- Branch `simplify-feedback`; one commit per task group below; commit messages **without** any Claude co-author line; **no push**.
- Every visible string in FR and EN (`src/i18n/fr.ts`, `src/i18n/en.ts`); remove keys that become unused.
- Old projects (IndexedDB and `.json`) open without error: every removed/renamed field is handled in `migrateProject` (`src/store/persistence.ts`).
- "Paramètres avancés" (`Advanced` in `src/ui/primitives.tsx`) only holds fine-tuning; background colour, adding a device and video export stay one click away.
- Network interfaces are generic: no logo, no brand name of a network anywhere in the UI or exports (labels are "Post Insta", "Story", "TikTok / Reel", "YouTube" as format names only, as today).
- The guide (`src/shell/Tour.tsx` STEPS + `tour.*` keys) is updated whenever a task removes or moves a part it presents.
- Tests are Playwright scripts `scripts/check-*.mjs` using `openApp`/`check`/`done` from `scripts/lib/app.mjs`; each task's script must print only `✓` lines and `no console errors`. All existing `check-*.mjs` pass at the end of each phase (adapt the ones whose UI changed), plus `npm run build`.

## Review Focus

- A project saved with `decor.kind = 'surface'` reopens showing "Vraie table" selected with "Sans la pièce" on (Task 3 test).
- A project saved in a carousel ratio (`c3-4x5`) reopens as `ig-post` with one image, no slide guides (Task 6 test).

- Escape during a video preview started from the Export window stops it and the window comes back on the Vidéo tab (Task 5 test).
