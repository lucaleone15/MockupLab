## Résolu

- Accueil : plus de dépôt direct ; « Ouvrir le Studio » dans le premier écran ; carte Studio en grand, puis Rapide,
  Projet, Photo, chacun avec une phrase qui dit à quoi il sert. Coller une image sur l'accueil affiche
  « Choisis d'abord un mode… ».
- En-tête : Studio · Rapide · Projet · Photo, infobulle avec le rôle du mode.
- État vide de chaque mode : une ligne qui dit à quoi il sert.
- Studio : « Idées » devient « Varier ma scène » (infobulle : garde tes appareils et tes textes) ; Rapide et Projet :
  « Affiner dans le Studio ».
- Studio : s'ouvre sur **Appareils** (audit n°4).
- Le premier appareil choisi **remplace** le téléphone d'exemple s'il est resté intact (audit n°3 — le téléphone
  n'avait jamais disparu : un clic ajoutait toujours).
- Carte de visite reconnue (nom du fichier, ratio 85×55 / 89×51 hors largeurs d'écran) et posée sur une carte de
  visite, pas sur une affiche (audit n°6).
- Marque d'exemple signalée, avec « Partir de zéro » (audit n°7).
- Mode Photo : « parcourir » dans le bandeau (audit n°8).
- Cadrage plus serré : un appareil remplit 86 % du cadre, une composition 80 % (audit n°13).

## Vérifié, sans changement

- Vitesse des vignettes Rapide (audit n°10) : 16 vignettes en 5 s, première rangée en 1,5 s ; la capture de l'audit
  avait été prise trop tôt.
